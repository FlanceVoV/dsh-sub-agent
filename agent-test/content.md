## 1 页面文案
- 标题：子 Agent 协作金字塔
- 副标题：DSH 0.2.0 任务链 · 9 个任务 · 5 层 · 3 个 agent
- 一句话描述：用 1/2/3/2/1 的金字塔形状，展示一条带依赖的任务链如何并行与串行展开。
- 页脚一句话：本页面由三个能力各异的子 agent 通过任务链协作产出。
